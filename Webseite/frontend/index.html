Wie es funktioniert

Vom Polygon zur Zonenkarte in Sekunden

Wähle das Polygon-Zeichenwerkzeug auf der Karte, klicke die Ecken deiner Landwirtschaftsfläche ab und starte die Analyse.

Das FastAPI-Backend unterteilt die Bounding-Box in ein 4×4-Gitter und berechnet für jede Zelle einen Qualitätswert über dein ML-Modell.

ML-Modell

Plug-in dein eigenes Modell

Das Template liefert einen Platzhalter, der räumlich variierende Werte simuliert. Ersetze ihn mit deinem trainierten scikit-learn, XGBoost oder PyTorch Modell.

Features extrahieren, Modell laden, Wert zurückgeben — drei Zeilen Code genügen.

Über AgroScan

Wir verbinden Landwirtschaft mit moderner KI.

AgroScan ist ein Open-Source-Starter-Template für ML-gestützte Flächenanalyse. Entwickelt für Forscher, Agrar-Startups und Bauernbetriebe, die ihr eigenes Modell schnell in eine kartographische Anwendung einbetten wollen.

Mission

Warum AgroScan?

"Präzisionslandwirtschaft sollte nicht an der technischen Komplexität scheitern. Unser Ziel ist ein Template, das in Stunden produktionsreif ist — nicht Wochen."

Satellitendaten, Bodensensoren, Wetterdienste — die Daten sind vorhanden. Was fehlt, ist ein einfaches Framework, das kartographische Visualisierung mit einem austauschbaren ML-Backend verbindet. AgroScan füllt diese Lücke.
