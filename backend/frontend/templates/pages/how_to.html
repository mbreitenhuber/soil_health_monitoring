    {% if lang == "en" %}

  2. Continue clicking along the field boundary to add more points.
  3. Placed a corner in the wrong spot? Click Undo last point in the toolbar to remove the most recent point and try again.
  4. Close the polygon by clicking on the first point again, or press Finish in the toolbar.
  5. To adjust the shape afterwards, select Edit layers (pencil icon), drag the corner handles to move them, then click Save changes to apply the new outline.
    6. {% else %}
  6. Klicke einmal auf die Karte, um die erste Ecke deines Feldes zu setzen.
  7. Klicke entlang der Feldgrenze weiter, um weitere Punkte hinzuzufügen.
  8. Falsche Ecke gesetzt? Klicke in der Werkzeugleiste auf Rückgängig, um den zuletzt gesetzten Punkt zu entfernen.
  9. Schliesse das Polygon, indem du erneut auf den ersten Punkt klickst, oder wähle Beenden in der Werkzeugleiste.

{{ "Under the hood" if lang == "en" else "Im Hintergrund" }}

{{ "About the ML model & data" if lang == "en" else "ML-Modell & Daten" }}

{% if lang == "en" %} Machine learning is a way of teaching a computer to recognize patterns without programming every rule by hand. Instead of telling the computer exactly what to look for, you show it a lot of real examples with known answers. It studies those examples, finds the patterns in the provided data, and uses them to make predictions on new data it has never seen before. The more examples it learns from, the better its predictions become. And this exactly what we did with AgroScan! {% else %} Machine Learning bedeutet, einem Computer beizubringen, Muster zu erkennen, ohne jede Regel von Hand zu programmieren. Statt genau vorzugeben, wonach gesucht wird, zeigt man viele Beispiele mit bekannten Antworten. Das System lernt daraus Muster und nutzt sie für Vorhersagen bei neuen, unbekannten Daten. Je mehr Beispiele, desto besser die Vorhersagen. Und Genau so haben wir AgroScan aufgebaut! {% endif %}

{{ "1. Satellites provide the data for our prediction" if lang == "en" else "1. Satelliten liefern die Daten für unsere Vorhersage" }}

{% if lang == "en" %} Every five days, the European Sentinel-2 satellite passes over your field and records how it reflects sunlight not just in colors you can see, but in invisible wavelengths that reveal information about vegetation health, moisture levels, and soil composition. AgroScan analyses these spectral "fingerprints" to estimate how much organic carbon is stored in your topsoil. {% else %} Alle fünf Tage überfliegt der europäische Sentinel-2-Satellit dein Feld und misst die Lichtreflexion, nicht nur in sichtbaren Farben, sondern auch in unsichtbaren Wellenlängen mit Informationen zu Vegetation, Feuchte und Bodenzusammensetzung. AgroScan wertet diese spektralen „Fingerabdrücke“ aus, um den organischen Kohlenstoff in deinem Oberboden zu schätzen. {% endif %}

{{ "2. We train our model using real ground soil samples" if lang == "en" else "2. Wir trainieren das Modell mit echten Bodenproben" }}

{% if lang == "en" %} Before making any prediction, our system was trained on soil measurements collected across Germany as part of the EU-wide LUCAS soil survey, so samples that were physically taken from the ground and analyzed in a laboratory. By finding patterns between those confirmed measurements and the satellite images taken at the same locations, the model learned to recognized what high and low carbon soils look like from space. {% else %} Vor jeder Vorhersage wurde unser System mit Bodenmessungen aus ganz Deutschland trainiert, im Rahmen der EU-weiten LUCAS-Bodenerhebung, also Proben vom Feld, analysiert im Labor. Aus Mustern zwischen diesen Messungen und Satellitenbildern am selben Ort lernte das Modell, wie kohlenstoffreiche und -arme Böden aus dem All aussehen. {% endif %}

{% if lang == "en" %} Think of it like this: if you showed a system thousands of photos of cats and dogs with labels, it would learn to recognize the animal from visual cues alone. AgroScan does the same except it learned from soil, satellites, and the wavelengths of reflected light. {% else %} Stell es dir so vor: Zeigst du einem System tausende beschriftete Katzen- und Hundefotos, erkennt es das Tier allein an visuellen Merkmalen. AgroScan macht dasselbe, nur mit Boden, Satelliten und reflektiertem Licht. {% endif %}

{{ "3. AgroScan estimates the SOC values for your field" if lang == "en" else "3. AgroScan schätzt die SOC-Werte für dein Feld" }}

{% if lang == "en" %} Using the patterns learned during training, AgroScan predicts the SOC value in your selected field. The value is only an estimate and not a lab measurement. It is good at prediction for fields similar to the training data from Germany.
