{{ "Step 1" if lang == "en" else "Schritt 1" }}

{{ "Navigate to the Analysis page" if lang == "en" else "Zur Analyse-Seite wechseln" }}

{% if lang == "en" %} Open the Analysis page via Analysis in the top navigation or the Analyze now button on the home page. A full-screen satellite map opens, centred on Germany by default. On the left you will find a sidebar with short instructions to help you through the process; for the full walkthrough, you are already in the right place. {% else %} Öffne die Analyse-Seite über Analyse in der oberen Navigation oder den Button Jetzt analysieren auf der Startseite. Eine Vollbild-Satellitenkarte öffnet sich, standardmässig mit Fokus auf Deutschland. Links findest du eine Seitenleiste mit kurzen Anweisungen als Hilfe für den Ablauf; die ausführliche Anleitung liest du hier. {% endif %}

{% if lang == "en" %} Before you draw anything, zoom and pan to your field. The map behaves like any familiar online map: scroll to zoom, click and drag to move. A search bar in the top-right corner lets you jump to a place name or enter coordinates directly, which is often faster than scrolling across the country from the default view. {% else %} Bevor du etwas zeichnest, zoome und verschiebe die Karte zu deinem Feld. Sie verhält sich wie eine gewohnte Online-Karte: Scrollen zum Zoomen, Klicken und Ziehen zum Verschieben. Die Suchleiste oben rechts springt zu einem Ortsnamen oder direkt zu Koordinaten, was oft schneller, als vom Standardausschnitt quer durchs Land zu scrollen. {% endif %}

💡 {{ "Tip" if lang == "en" else "Tipp" }} {% if lang == "en" %} AgroScan works best for agricultural fields in Germany. When the page loads, a short note reminds you of a few practical limits. For example, very large fields take longer to process and the page should stay open while the model is running. {% else %} AgroScan eignet sich am besten für landwirtschaftliche Felder in Deutschland. Beim Laden erscheint kurz ein Hinweis zu ein paar praktischen Grenzen. Zum Beispiel dauern sehr grosse Felder länger, und die Seite sollte während der Modellberechnung geöffnet bleiben. {% endif %}
{{ "Step 2" if lang == "en" else "Schritt 2" }}

{{ "Draw your field polygon" if lang == "en" else "Feld-Polygon zeichnen" }}

{% if lang == "en" %} In the top-left corner of the map you will find the drawing toolbar. Select the Polygon tool (the pentagon icon, second from the top). Then: {% else %} Oben links auf der Karte findest du die Zeichenwerkzeuge. Wähle das Polygon-Werkzeug (Pentagon-Symbol, zweites von oben). Dann: {% endif %}

    {% if lang == "en" %}
  1. Click once on the map to place the first corner of your field.
  2. Continue clicking along the field boundary to add more points.
  3. Placed a corner in the wrong spot? Click Undo last point in the toolbar to remove the most recent point and try again.
  4. Close the polygon by clicking on the first point again, or press Finish in the toolbar.
  5. To adjust the shape afterwards, select Edit layers (pencil icon), drag the corner handles to move them, then click Save changes to apply the new outline.
    6. {% else %}
  6. Klicke einmal auf die Karte, um die erste Ecke deines Feldes zu setzen.
  7. Klicke entlang der Feldgrenze weiter, um weitere Punkte hinzuzufügen.
  8. Falsche Ecke gesetzt? Klicke in der Werkzeugleiste auf Rückgängig, um den zuletzt gesetzten Punkt zu entfernen.
  9. Schliesse das Polygon, indem du erneut auf den ersten Punkt klickst, oder wähle Beenden in der Werkzeugleiste.
  10. Zum Nachbearbeiten wähle Layer bearbeiten (Stift-Symbol), ziehe die Eckpunkte an die gewünschte Position und klicke auf Speichern.
    11. {% endif %}

{% if lang == "en" %} To start over after an analysis, use Reset in the sidebar. While drawing a new field, you can also delete the polygon with the map toolbar and draw again. {% else %} Für einen Neustart nach einer Analyse nutze Zurücksetzen in der Seitenleiste. Beim Zeichnen eines neuen Feldes kannst du das Polygon auch über die Karten-Werkzeugleiste löschen und neu zeichnen. {% endif %}

💡 {{ "Tip" if lang == "en" else "Tipp" }} {% if lang == "en" %} You do not need to be pixel-perfect. A rough outline is enough for a meaningful zone map. You can use Undo last point while drawing and Edit layers / Save changes for small corrections without redrawing the whole field. {% else %} Pixelgenauigkeit ist nicht nötig. Eine grobe Umrandung reicht für eine aussagekräftige Zonenkarte. Nutze Rückgängig beim Zeichnen sowie Layer bearbeiten / Speichern für kleine Korrekturen, ohne das ganze Feld neu zu zeichnen. {% endif %}
{{ "Step 3" if lang == "en" else "Schritt 3" }}

{{ "Select the analysis date" if lang == "en" else "Analysedatum wählen" }}

{% if lang == "en" %} Every analysis is tied to a specific point in time. AgroScan uses Sentinel-2 satellite imagery, and the model needs to know which acquisition date to use for your field. Once your polygon is in place, choose an Analysis date in the sidebar. This tells the system which satellite pass to base the prediction on. {% else %} Jede Analyse bezieht sich auf einen bestimmten Zeitpunkt. AgroScan nutzt Sentinel-2-Satellitenbilder, und das Modell muss wissen, welches Aufnahmedatum für dein Feld verwendet werden soll. Sobald dein Polygon steht, wählst du in der Seitenleiste ein Analysedatum. Damit legst du fest, welcher Satellitendurchgang der Vorhersage zugrunde liegt. {% endif %}

{% if lang == "en" %} Open the date picker and select a day from the calendar. Future dates are not available because no satellite image exists yet. If you want the most recent data without browsing the calendar, use Select today to set today's date in one click. Comparing the same field across different dates over several weeks or seasons is one of the most useful ways to track how your soil carbon changes over time. {% else %} Öffne die Datumsauswahl und wähle einen Tag im Kalender. Zukünftige Daten sind nicht verfügbar, weil es dafür noch kein Satellitenbild gibt. Willst du die aktuellsten Daten ohne Kalendersuche, setzt Heute wählen das heutige Datum mit einem Klick. Dasselbe Feld an verschiedenen Daten über Wochen oder Saisons hinweg zu vergleichen, ist eine der besten Methoden, um Veränderungen des Bodenkohlenstoffs zu verfolgen. {% endif %}

{{ "Step 4" if lang == "en" else "Schritt 4" }}

{{ "Start the analysis" if lang == "en" else "Analyse starten" }}

{% if lang == "en" %} With your field outlined and a date selected, click Start analysis. AgroScan downloads the relevant satellite tiles for your polygon, runs them through the machine-learning model, and divides the field into a grid of 60-metre zones. Each zone receives a predicted soil organic carbon value, which is then colour-coded on the map. A loading message appears while this runs. How long it takes depends mainly on field size and your internet connection. {% else %} Mit umrissener Fläche und gewähltem Datum klickst du auf Analyse starten. AgroScan lädt die passenden Satellitenkacheln für dein Polygon, führt sie durch das Machine-Learning-Modell und unterteilt das Feld in ein Raster aus 60-Meter-Zonen. Jede Zone erhält einen vorhergesagten Wert für organischen Bodenkohlenstoff, der auf der Karte farblich dargestellt wird. Währenddessen erscheint eine Lademeldung. Die Dauer hängt vor allem von der Feldgrösse und deiner Internetverbindung ab. {% endif %}

{% if lang == "en" %} Keep the browser tab open until the process finishes. If something goes wrong, for example a dropped connection, you can simply try again. For the most reliable results, analyse individual fields or management zones separately rather than drawing one very large polygon around several parcels at once. {% else %} Lass den Browser-Tab geöffnet, bis der Vorgang abgeschlossen ist. Bei Problemen, etwa einer unterbrochenen Verbindung, kannst du es einfach erneut versuchen. Für verlässliche Ergebnisse analysierst du einzelne Felder oder Bewirtschaftungszonen getrennt, statt ein sehr grosses Polygon um mehrere Parzellen zu legen. {% endif %}

⚠️ {{ "Note" if lang == "en" else "Hinweis" }} {% if lang == "en" %} The analysis requires an active internet connection to download satellite data. Larger fields produce more grid cells and take longer to process. {% else %} Für die Analyse brauchst du eine aktive Internetverbindung zum Herunterladen der Satellitendaten. Grössere Felder erzeugen mehr Rasterzellen und brauchen länger. {% endif %}
{{ "Step 5" if lang == "en" else "Schritt 5" }}

{{ "Read your results" if lang == "en" else "Ergebnisse lesen" }}

{% if lang == "en" %} After the analysis is completed, your field will be color-coded based on the predicted soil organic carbon content. The Result section appears in the sidebar with the number of zones analyzed, the average SOC content, and the highest and lowest SOC values. {% else %} Nach Abschluss der Analyse wird dein Feld nach dem vorhergesagten organischen Kohlenstoff im Boden farbcodiert. Der Bereich Ergebnis erscheint in der Seitenleiste mit der Anzahl analysierter Zonen, dem durchschnittlichen SOC sowie den höchsten und niedrigsten SOC-Werten. {% endif %}

{{ "Under the hood" if lang == "en" else "Im Hintergrund" }}

{{ "About the ML model & data" if lang == "en" else "ML-Modell & Daten" }}

{% if lang == "en" %} Machine learning is a way of teaching a computer to recognize patterns without programming every rule by hand. Instead of telling the computer exactly what to look for, you show it a lot of real examples with known answers. It studies those examples, finds the patterns in the provided data, and uses them to make predictions on new data it has never seen before. The more examples it learns from, the better its predictions become. And this exactly what we did with AgroScan! {% else %} Machine Learning bedeutet, einem Computer beizubringen, Muster zu erkennen, ohne jede Regel von Hand zu programmieren. Statt genau vorzugeben, wonach gesucht wird, zeigt man viele Beispiele mit bekannten Antworten. Das System lernt daraus Muster und nutzt sie für Vorhersagen bei neuen, unbekannten Daten. Je mehr Beispiele, desto besser die Vorhersagen. Und Genau so haben wir AgroScan aufgebaut! {% endif %}

{{ "1. Satellites provide the data for our prediction" if lang == "en" else "1. Satelliten liefern die Daten für unsere Vorhersage" }}

{% if lang == "en" %} Every five days, the European Sentinel-2 satellite passes over your field and records how it reflects sunlight not just in colors you can see, but in invisible wavelengths that reveal information about vegetation health, moisture levels, and soil composition. AgroScan analyses these spectral "fingerprints" to estimate how much organic carbon is stored in your topsoil. {% else %} Alle fünf Tage überfliegt der europäische Sentinel-2-Satellit dein Feld und misst die Lichtreflexion, nicht nur in sichtbaren Farben, sondern auch in unsichtbaren Wellenlängen mit Informationen zu Vegetation, Feuchte und Bodenzusammensetzung. AgroScan wertet diese spektralen „Fingerabdrücke“ aus, um den organischen Kohlenstoff in deinem Oberboden zu schätzen. {% endif %}

{{ "2. We train our model using real ground soil samples" if lang == "en" else "2. Wir trainieren das Modell mit echten Bodenproben" }}

{% if lang == "en" %} Before making any prediction, our system was trained on soil measurements collected across Germany as part of the EU-wide LUCAS soil survey, so samples that were physically taken from the ground and analyzed in a laboratory. By finding patterns between those confirmed measurements and the satellite images taken at the same locations, the model learned to recognized what high and low carbon soils look like from space. {% else %} Vor jeder Vorhersage wurde unser System mit Bodenmessungen aus ganz Deutschland trainiert, im Rahmen der EU-weiten LUCAS-Bodenerhebung, also Proben vom Feld, analysiert im Labor. Aus Mustern zwischen diesen Messungen und Satellitenbildern am selben Ort lernte das Modell, wie kohlenstoffreiche und -arme Böden aus dem All aussehen. {% endif %}

{% if lang == "en" %} Think of it like this: if you showed a system thousands of photos of cats and dogs with labels, it would learn to recognize the animal from visual cues alone. AgroScan does the same except it learned from soil, satellites, and the wavelengths of reflected light. {% else %} Stell es dir so vor: Zeigst du einem System tausende beschriftete Katzen- und Hundefotos, erkennt es das Tier allein an visuellen Merkmalen. AgroScan macht dasselbe, nur mit Boden, Satelliten und reflektiertem Licht. {% endif %}

{{ "3. AgroScan estimates the SOC values for your field" if lang == "en" else "3. AgroScan schätzt die SOC-Werte für dein Feld" }}

{% if lang == "en" %} Using the patterns learned during training, AgroScan predicts the SOC value in your selected field. The value is only an estimate and not a lab measurement. It is good at prediction for fields similar to the training data from Germany. The model's predictions become less accurate the more the test field differs from the training fields. {% else %} Mit den Trainingsmustern sagt AgroScan den SOC-Wert für dein ausgewähltes Feld voraus. Es handelt sich um eine Schätzung, keine Labor-Messung. Die Vorhersage ist am zuverlässigsten für Felder, die den Trainingsdaten aus Deutschland ähneln. Je stärker dein Feld abweicht, desto ungenauer werden die Werte. {% endif %}

{% if lang == "en" %} The model gives you an indication of your soil's carbon status and, more importantly, how that status changes over time. A single prediction tells you where you stand today. A series of predictions across seasons tells you whether your soil management practices are working. {% else %} Das Modell zeigt dir den Kohlenstoffstatus deines Bodens und vor allem, wie er sich über die Zeit verändert. Eine einzelne Vorhersage sagt, wo du heute stehst; eine Serie über mehrere Saisons zeigt, ob deine Bodenbewirtschaftung wirkt. {% endif %}
