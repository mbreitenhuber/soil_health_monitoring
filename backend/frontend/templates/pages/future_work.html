{{ "What’s coming to the product" if lang == "en" else "Was als Nächstes ins Produkt kommt" }}

{% if lang == "en" %} These ideas focus on day-to-day usability, better guidance, and community. They’re written as a preview — the exact UX and implementation details will evolve. {% else %} Diese Ideen fokussieren sich auf bessere Nutzbarkeit im Alltag, mehr Unterstützung und Community. Sie sind als Vorschau gedacht — UX und Details werden sich bei der Umsetzung weiterentwickeln. {% endif %}

1. {{ "Community forum" if lang == "en" else "Community-Forum" }}

{% if lang == "en" %} Connect with fellow farmers on their sustainable farming journey: profile + interest-based groups + direct messages, and a place to propose new AgroScan ideas. {% else %} Vernetzt euch mit anderen Landwirt:innen auf dem Weg zu nachhaltiger Landwirtschaft: Profil + themenbasierte Gruppen + Direktnachrichten und ein Ort, um neue AgroScan-Ideen vorzuschlagen. {% endif %}

2. {{ "Chatbot recommendations" if lang == "en" else "Chatbot-Empfehlungen" }}

{% if lang == "en" %} A chatbot for sustainable soil management practice recommendations — trained on academic knowledge and local farmer experience — including guidance on techniques, incentives, and carbon-credit ideas. {% else %} Ein Chatbot für Empfehlungen zu nachhaltigem Bodenmanagement — trainiert mit akademischem Wissen und lokalen Erfahrungen — inklusive Hilfe zu Techniken, Incentives und Carbon-Credit-Ideen. {% endif %}

3. {{ "Baseline / historic analysis" if lang == "en" else "Baseline- & Historienanalyse" }}

{% if lang == "en" %} Select your field and a time period, then automatically run historic quarterly analyses and summarize them in a simple line chart to establish a baseline. {% else %} Feld und Zeitraum auswählen, dann automatisch historische Quartals-Analysen durchführen und als einfache Liniengrafik zusammenfassen — als Baseline für den Start. {% endif %}

4. {{ "Track your progress" if lang == "en" else "Fortschritt tracken" }}

{% if lang == "en" %} Set SOC goals, track progress over time, and add a bit of fun via light gamification to stay motivated. {% else %} SOC-Ziele setzen, Fortschritt über Zeit verfolgen und mit leichter Gamification Motivation schaffen. {% endif %}

5. {{ "Loading page reinvented" if lang == "en" else "Loading-Page neu gedacht" }}

{% if lang == "en" %} A loading page that shows exactly which step the pipeline is currently running — so waiting feels transparent and predictable. {% else %} Eine Loading-Page, die transparent zeigt, in welchem Pipeline-Schritt die Analyse gerade steckt — damit Wartezeit nachvollziehbar wird. {% endif %}

{{ "Technology features" if lang == "en" else "Technologie-Features" }}

{{ "Model improvement roadmap" if lang == "en" else "Roadmap für Modellverbesserungen" }}

{% if lang == "en" %} In parallel, we want to improve the model and extend the scope of what we can estimate from remote sensing and local input. {% else %} Parallel wollen wir das Modell verbessern und den Umfang erweitern, was wir aus Fernerkundung und lokalem Input ableiten können. {% endif %}

1. {{ "Enlarge feature input" if lang == "en" else "Mehr Input-Features" }}

{% if lang == "en" %} Beyond Sentinel-2: include Sentinel-1, weather, and elevation data to improve accuracy. {% else %} Über Sentinel-2 hinaus: Sentinel-1, Wetter- und Höhendaten integrieren, um die Genauigkeit zu erhöhen. {% endif %}

2. {{ "Integrate local input" if lang == "en" else "Lokalen Input integrieren" }}

{% if lang == "en" %} Bridge remote sensing and local knowledge: upload a soil photo, add measurements, and specify soil type. {% else %} Fernerkundung und lokales Wissen verbinden: Bodenfoto hochladen, Messwerte angeben und Bodentyp definieren. {% endif %}

3. {{ "Predict more soil characteristics" if lang == "en" else "Mehr Bodenparameter vorhersagen" }}

{% if lang == "en" %} Extend beyond SOC: soil moisture, pH value, and additional nutrient levels to support targeted irrigation and variable-rate fertilization. {% else %} Über SOC hinaus: Bodenfeuchte, pH-Wert und weitere Nährstoff-Level, um gezielte Bewässerung und variable Düngung zu unterstützen. {% endif %}

4. {{ "Improve resolution" if lang == "en" else "Auflösung verbessern" }}

{% if lang == "en" %} Reduce grid size from 60×60 m to 10×10 m to capture within-field SOC variability in more detail. {% else %} Die Zellgröße von 60×60 m auf 10×10 m reduzieren, um Intra-Feld-Variabilität detaillierter sichtbar zu machen. {% endif %}

{% if lang == "en" %} Last but not least: if you’re missing a feature, tell us in the GitHub repository or later in the community forum’s “AgroScan Development” group. {% else %} Last but not least: Falls euch ein Feature fehlt, sagt uns Bescheid im GitHub-Repository oder später im Community-Forum in der Gruppe „AgroScan Development“. {% endif %}
