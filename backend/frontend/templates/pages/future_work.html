{{ "What’s coming to the product" if lang == "en" else "Was als Nächstes ins Produkt kommt" }}

{% if lang == "en" %} These ideas focus on day-to-day usability, better guidance, and community. They’re written as a preview. 1. {{ "Community forum" if lang == "en" else "Community-Forum" }}

{% if lang == "en" %} Connect with fellow farmers on their sustainable farming journey: profile + interest-based groups + direct messages, and a place to propose new AgroScan ideas. {% else %} Vernetze dich mit anderen Landwirt:innen auf dem Weg zu nachhaltiger Landwirtschaft: Profile, interessenbasierte Gruppen und Direktnachrichten sowie ein Ort, um neue AgroScan-Ideen einzubringen. {% endif %}

2. {{ "Chatbot recommendations" if lang == "en" else "Chatbot-Empfehlungen" }}

{% if lang == "en" %} A chatbot for sustainable soil management practice recommendations, trained on academic knowledge and local farmer experience, including guidance on techniques, incentives, and carbon-credit ideas. {% else %} Ein Chatbot für Empfehlungen zu nachhaltigem Bodenmanagement, trainiert mit wissenschaftlichen Erkenntnissen und Erfahrungen aus der Landwirtschaft, inklusive Hinweise zu Methoden, Förderungen und Carbon-Credit-Ideen. {% endif %}

3. {{ "Baseline / historic analysis" if lang == "en" else "Baseline- & Verlaufsanalyse" }}

{% if lang == "en" %} Select your field and a time period, then automatically run historic quarterly analyses and summarize them in a simple line chart to establish a baseline. {% else %} Wähle ein Feld und einen Zeitraum aus, anschliessend werden historische Quartalsanalysen automatisch berechnet und in einem einfachen Liniendiagramm als Baseline zusammengefasst. {% endif %}

4. {{ "Track your progress" if lang == "en" else "Fortschritt verfolgen" }}

{% if lang == "en" %} Set SOC goals, track progress over time, and add a bit of fun via light gamification to stay motivated. {% else %} Setze SOC-Ziele, verfolge deinen Fortschritt über die Zeit und bleibe durch leichte Gamification motiviert. {% endif %}

5. {{ "Updating loading page" if lang == "en" else "Lade-Seite überarbeiten" }}

{% if lang == "en" %} A loading page that shows exactly which step the pipeline is currently running, so waiting feels transparent and predictable. {% else %} Eine Loading Page, die transparent zeigt, in welchem Schritt der Pipeline sich die Analyse gerade befindet, damit Wartezeiten nachvollziehbar und planbar werden. {% endif %}

{{ "Technology features" if lang == "en" else "Technologie-Features" }}

{{ "Model improvement roadmap" if lang == "en" else "Roadmap zur Modellverbesserung" }}

{% if lang == "en" %} In parallel, we want to improve the model and extend the scope of what we can estimate from remote sensing and local input. {% else %} Parallel dazu möchten wir das Modell weiter verbessern und den Umfang der Schätzungen aus Fernerkundung und lokalen Eingaben erweitern. {% endif %}

1. {{ "Improve ML prediction" if lang == "en" else "ML-Vorhersage verbessern" }}

{% if lang == "en" %} Key areas for improving the SOC prediction model: {% else %} Zentrale Verbesserungsmöglichkeiten für das SOC-Vorhersagemodell: {% endif %}

    {% if lang == "en" %}
  • Accuracy — reduce prediction error through better features, model tuning, and validation on held-out fields.
  • Generalizability — ensure reliable estimates across regions, soil types, and land-use conditions beyond the current training distribution.
  • Uncertainty estimation — quantify and communicate prediction uncertainty so users can judge how much to trust a result.
  • Data foundation — expand and diversify the training dataset (e.g. LUCAS 2022, neighboring EU countries) beyond the current n=270 samples.
    • {% else %}
  • Genauigkeit — Vorhersagefehler durch bessere Features, Modelloptimierung und Validierung auf ungesehenen Feldern reduzieren.
  • Generalisierbarkeit — zuverlässige Schätzungen über Regionen, Bodentypen und Landnutzungen hinweg sicherstellen, auch ausserhalb der aktuellen Trainingsverteilung.
  • Unsicherheitsabschätzung — Vorhersageunsicherheit quantifizieren und transparent kommunizieren, damit Nutzer:innen die Verlässlichkeit einschätzen können.
  • Datengrundlage — Trainingsdatensatz erweitern und diversifizieren (z. B. LUCAS 2022, benachbarte EU-Länder) über die aktuellen n=270 Stichproben hinaus.
    • {% endif %}

2. {{ "Enlarge feature input" if lang == "en" else "Erweiterte Input-Features" }}

{% if lang == "en" %} Beyond Sentinel-2: include Sentinel-1, weather, and elevation data to improve accuracy. {% else %} Über Sentinel-2 hinaus sollen künftig auch Sentinel-1, Wetterdaten und Höhenmodelle integriert werden, um die Genauigkeit zu verbessern. {% endif %}

3. {{ "Integrate local input" if lang == "en" else "Lokale Daten integrieren" }}

{% if lang == "en" %} Bridge remote sensing and local knowledge: upload a soil photo, add measurements, and specify soil type. {% else %} Fernerkundung und lokales Wissen verbinden: Bodenfotos hochladen, Messwerte ergänzen und den Bodentyp angeben. {% endif %}

4. {{ "Predict more soil characteristics" if lang == "en" else "Erweiterte Bodenparameter" }}

{% if lang == "en" %} Extend beyond SOC: soil moisture, pH value, and additional nutrient levels to support targeted irrigation and variable-rate fertilization. {% else %} Über SOC hinaus sollen künftig auch Bodenfeuchte, pH-Wert und weitere Nährstoffparameter vorhergesagt werden, um gezielte Bewässerung und variable Düngung zu unterstützen. {% endif %}

5. {{ "Improve resolution" if lang == "en" else "Höhere räumliche Auflösung" }}

{% if lang == "en" %} Reduce grid size from 60×60 m to 10×10 m to capture within-field SOC variability in more detail. {% else %} Die Rasterauflösung soll von 60×60 m auf 10×10 m reduziert werden, um die räumliche SOC-Variabilität innerhalb eines Feldes deutlich detaillierter abzubilden. {% endif %}
