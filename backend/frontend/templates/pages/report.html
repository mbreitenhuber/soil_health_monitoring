{{ "Introduction" if lang == "en" else "Einleitung" }}

{% if lang == "en" %} Soils represent the largest terrestrial carbon pool globally and play a critical role as carbon sinks through soil carbon sequestration, where atmospheric CO₂ is stored as soil organic matter via photosynthesis (Paustian et.al, 2019)[1]. Agricultural soils with high soil organic carbon (SOC) content deliver significant environmental and agronomic co- benefits: improved long-term productivity, increased biodiversity, and preservation of ecosystem services (Europ. Commission, 2019)[2]. {% else %} Böden repräsentieren weltweit den grössten terrestrischen Kohlenstoffpool und erfüllen eine zentrale Funktion als Kohlenstoffsenken: Durch Bodensequestrierung wird atmosphärisches CO₂ im Rahmen der Photosynthese als organische Substanz im Boden gebunden (Paustian et.al, 2019)[1]. Landwirtschaftliche Böden mit hohem Gehalt an organischem Bodenkohlenstoff (SOC) weisen signifikante ökologische und agronomische Co-Benefits auf — darunter eine verbesserte langfristige Produktivität, eine gesteigerte Biodiversität sowie den Erhalt von Ökosystemleistungen (Europ. Commission, 2019)[2]. {% endif %}

{% if lang == "en" %} Consequently, monitoring and enhancing SOC stocks has become a priority within major policy frameworks, including the EU Soil Strategy for 2030 that translates into the EU Soil Monitoring Law (Europ. Commission, 2019[2]; Europ. Parliament, 2025)[3]. {% else %} Infolgedessen rücken die Überwachung und der Ausbau von SOC-Vorräten zu einer Priorität innerhalb zentraler politischer Rahmenwerke — darunter die EU-Bodenstrategie für 2030, die in das EU-Bodenüberwachungsgesetz mündet (Europ. Commission, 2019[2]; Europ. Parliament, 2025)[3]. {% endif %}

{% if lang == "en" %} Despite this recognized importance, farmers face substantial barriers when integrating SOC monitoring into their agricultural practices. Conventional soil sampling requires repeated field and laboratory work across extended time periods, creating significant cost, labor, and scalability constraints that limit routine application across large agricultural areas (Ihasusta et.al., 2026)[4]. {% else %} Trotz dieser anerkannten Bedeutung bestehen für Landwirtinnen und Landwirte erhebliche Barrieren bei der Integration von SOC-Monitoring in die landwirtschaftliche Praxis. Die konventionelle Bodenprobenahme erfordert wiederholte Feld- und Laborarbeit über längere Zeiträume und geht mit signifikanten Kosten-, Arbeits- und Skalierungsproblemen einher, die eine routinemässige Anwendung auf grossen landwirtschaftlichen Flächen einschränken (Ihasusta et.al., 2026)[4]. {% endif %}

{% if lang == "en" %} Machine learning-based remote sensing models have emerged as a promising approach to address these limitations. By leveraging satellite-derived data, these models offer scalable and cost-efficient SOC estimation and allow a baseline to be established using historic satellite imagery to assess the impact of sustainable soil management (SSM) practices over time. However, many existing tools remain restricted by paywalls, limited accessibility, or insufficient methodological transparency, constraining their adoption in both research and practice. {% else %} Fernerkundungsmodelle auf Basis maschinellen Lernens haben sich als vielversprechender Ansatz zur Überwindung dieser Limitationen etabliert. Durch die Auswertung satellitengestützter Daten ermöglichen sie skalierbare und kosteneffiziente SOC-Schätzungen und erlauben die Etablierung einer Referenzlinie anhand historischer Satellitenbilddaten, um die Wirkung nachhaltiger Bodenbewirtschaftung (SSM) über die Zeit zu beurteilen. Viele bestehende Werkzeuge sind jedoch durch Paywalls, eingeschränkte Zugänglichkeit oder unzureichende methodische Transparenz limitiert, was ihre Verbreitung in Forschung und Praxis hemmt. {% endif %}

{% if lang == "en" %} AgroScan addresses these gaps by providing a free, open-source platform that enables farmers to assess the SOC content of their fields, monitor the effectiveness of SSM practices, and engage with evidence when advocating to policymakers. As an open- source tool, it provides full transparency on the underlying methodology and allows users to personalize or extend the platform for their own use cases. {% else %} AgroScan adressiert diese Defizite mit einer kostenfreien Open-Source-Plattform, die Landwirtinnen und Landwirten die Bewertung des SOC-Gehalts ihrer Felder, die Überwachung der Wirksamkeit von SSM-Massnahmen sowie die Nutzung belastbarer Evidenz in der Interessenvertretung gegenüber politischen Entscheidungsträgerinnen und -trägern ermöglicht. Als Open-Source-Werkzeug gewährleistet AgroScan volle Transparenz hinsichtlich der zugrunde liegenden Methodik und erlaubt es Nutzerinnen und Nutzern, die Plattform für eigene Anwendungsfälle zu personalisieren oder zu erweitern. {% endif %}

{{ "Literature Review" if lang == "en" else "Literaturübersicht" }}

{% if lang == "en" %} The use of remote sensing combined with machine learning for SOC prediction in agricultural soils has become more established in academic research. Nguyen et al. (2022)[15] demonstrated a multi-sensor data fusion model combining multispectral image data from Sentinel-2 and synthetic aperture radar data from Sentinel-1, achieving high prediction accuracy (R² = 0.870, RMSE = 1.818 t/ha). The study highlighted that incorporating derived predictor features — including vegetation and soil indices calculated from raw band values — significantly improved model performance. {% else %} Die Kombination aus Fernerkundung und maschinellem Lernen zur SOC-Vorhersage in landwirtschaftlichen Böden ist in der wissenschaftlichen Literatur zunehmend etabliert. Nguyen et al. (2022)[15] entwickelten ein Multi-Sensor-Datenfusionsmodell, das multispektrale Bilddaten von Sentinel-2 mit SAR-Daten von Sentinel-1 kombiniert und eine hohe Vorhersagegenauigkeit erreichte (R² = 0,870, RMSE = 1,818 t/ha). Die Studie zeigt, dass abgeleitete Prädiktorvariablen — einschliesslich aus Rohbandwerten berechneter Vegetations- und Bodenindizes — die Modellleistung signifikant verbessern. {% endif %}

{% if lang == "en" %} Complementing this, Guo et al. (2021)[5] showed that Sentinel-2 optical data and crop- growth indices are particularly effective predictors for agricultural soils, which typically exhibit lower topological variability than other land use types. Similar results supporting the use of remote sensing for carbon prediction were demonstrated by Yuzugullu et.al. (2024)[21], Beisekenov et.al. (2025)[22], Zhang et.al. (2019)[23]. Taken together, these studies confirm that the technical foundation for remote sensing-based SOC prediction in agricultural contexts is well established. {% else %} Ergänzend zeigten Guo et al. (2021)[5], dass optische Sentinel-2-Daten und Wachstumsindizes der Pflanzenarten besonders wirksame Prädiktoren für landwirtschaftliche Böden darstellen, die typischerweise eine geringere topographische Variabilität als andere Landnutzungstypen aufweisen. Ähnliche Befunde zur Eignung der Fernerkundung für Kohlenstoffvorhersagen lieferten Yuzugullu et.al. (2024)[21], Beisekenov et.al. (2025)[22] und Zhang et.al. (2019)[23]. Insgesamt bestätigen diese Studien, dass die technische Grundlage für fernerkundungsbasierte SOC-Vorhersagen in landwirtschaftlichen Kontexten gut etabliert ist. {% endif %}

{% if lang == "en" %} Despite this academic progress, the translation into accessible farmer-facing tools remains limited. A review of existing commercial platforms shows a fragmented landscape. Providers such as Agricolus (AGRICOLUS s.r.l., n.d.)[6], OneSoil (OneSoil AG, n.d.)[8], and GeoPard Agriculture (FlyPard Analytics GmbH, n.d.)[7] offer a range of remote sensing-based services — including water stress monitoring and crop development tracking — but none advertise dedicated SOC prediction capabilities on their website. Farmonaut (Yuple Inc, n.d.)[9] represents the most directly relevant commercial offering, providing a carbon monitoring service. However, its platform discloses no information on the underlying methodology, data sources, or model validation. This lack of transparency showcases a broader pattern: where commercial tools exist, they tend to operate as black boxes, are largely behind paywalls, and offer users no agency to interact, adapt, or validate the tool for their specific regional or agronomic context. {% else %} Trotz dieses wissenschaftlichen Fortschritts bleibt die Umsetzung in zugängliche, landwirtschaftspraxisorientierte Werkzeuge begrenzt. Eine Übersicht bestehender kommerzieller Plattformen zeigt ein fragmentiertes Angebot. Anbieter wie Agricolus (AGRICOLUS s.r.l., n.d.)[6], OneSoil (OneSoil AG, n.d.)[8] und GeoPard Agriculture (FlyPard Analytics GmbH, n.d.)[7] bieten verschiedene fernerkundungsbasierte Dienstleistungen an — darunter Wasserstress-Monitoring und die Verfolgung der Pflanzenartentwicklung —, werben auf ihren Websites jedoch keinesfalls mit dedizierten SOC-Vorhersagefunktionen. Farmonaut (Yuple Inc, n.d.)[9] stellt das am ehesten vergleichbare kommerzielle Angebot dar und bietet einen Carbon-Monitoring-Dienst an. Die Plattform gibt jedoch keine Auskunft über die zugrunde liegende Methodik, die Datenquellen oder die Modellvalidierung. Diese mangelnde Transparenz verdeutlicht ein breiteres Muster: Wo kommerzielle Werkzeuge existieren, agieren sie häufig als Black Box, stehen weitgehend hinter Paywalls und gewähren Nutzerinnen und Nutzern keinen Handlungsspielraum, das Werkzeug für ihren regionalen oder agronomischen Kontext zu prüfen, anzupassen oder zu validieren. {% endif %}

{% if lang == "en" %} These gaps — limited availability, lack of methodological transparency and the absence of user agency — motivated the central research question of the present study: {% else %} Diese Defizite — begrenzte Verfügbarkeit, fehlende methodische Transparenz und der mangelnde Handlungsspielraum der Nutzerinnen und Nutzer — motivierten die zentrale Forschungsfrage der vorliegenden Studie: {% endif %}

{% if lang == "en" %} How can interactive machine learning be utilized to empower farmers to monitor and manage carbon stock in their agricultural soils? {% else %} Wie kann interaktives maschinelles Lernen genutzt werden, um Landwirtinnen und Landwirte zu befähigen, den Kohlenstoffvorrat in ihren landwirtschaftlichen Böden zu überwachen und zu steuern? {% endif %}

{% if lang == "en" %} AgroScan addresses this question by providing an open-source, methodologically transparent platform that enables farmers to query SOC predictions for their own fields and track changes over time, placing the farmer as an active participant rather than a passive end user. {% else %} AgroScan beantwortet diese Frage mit einer Open-Source-Plattform, die methodisch transparent ist und es Landwirtinnen und Landwirten ermöglicht, SOC-Vorhersagen für ihre eigenen Felder abzufragen und Veränderungen über die Zeit zu verfolgen — und sie dabei als aktive Akteurinnen und Akteure statt als passive Endnutzerinnen und Endnutzer positioniert. {% endif %}

{{ "Data methodology" if lang == "en" else "Datenmethodik" }}

{% if lang == "en" %} 1. Selection of case region
Germany was selected as the case region due to its significant agricultural sector, strong policy relevance, and high soil data availability. Around half of Germany’s land area is used for agriculture, making it one of the European Union’s largest agricultural producers (Federal Ministry of Food and Agriculture [BMEL], 2023)[11]. In addition, Germany must comply with the European Union Soil Monitoring Law by 2028, increasing the demand for scalable and cost-effective soil monitoring methods (European Union, 2025)[12]. AgroScan could support these future monitoring requirements through large-scale SOC assessments. Germany also offers strong data availability: The LUCAS 2019 soil dataset has 332 agricultural sampling locations in Germany, of which 270 could be matched to Sentinel-2 data (Fernández-Ugalde et.al., 2022)[24]; Fig. 1). {% else %} 1. Auswahl der Fallstudienregion
Deutschland wurde als Fallstudienregion ausgewählt, da der Agrarsektor des Landes bedeutend ist, die politische Relevanz hoch ist und umfangreiche Bodendaten verfügbar sind. Etwa die Hälfte der Landesfläche wird landwirtschaftlich genutzt; Deutschland zählt damit zu den grössten Agrarproduzenten der Europäischen Union (Federal Ministry of Food and Agriculture [BMEL], 2023)[11]. Zudem muss Deutschland bis 2028 das EU-Bodenüberwachungsgesetz umsetzen, was den Bedarf an skalierbaren und kosteneffizienten Bodenüberwachungsmethoden erhöht (European Union, 2025)[12]. AgroScan könnte diese künftigen Monitoring-Anforderungen durch grossflächige SOC-Bewertungen unterstützen. Darüber hinaus bietet Deutschland eine hohe Datenverfügbarkeit: Der LUCAS-2019-Bodendatensatz umfasst 332 landwirtschaftliche Probenahmestellen in Deutschland, von denen 270 mit Sentinel-2-Daten abgeglichen werden konnten (Fernández-Ugalde et.al., 2022)[24]; Abb. 1). {% endif %}

{% if lang == "en" %} 2. Data sources
Two publicly available and freely accessible datasets were selected as the foundation for the AgroScan model to support the project’s commitment to reproducibility and low barriers to adoption. {% else %} 2. Datenquellen
Als Grundlage für das AgroScan-Modell wurden zwei öffentlich verfügbare und frei zugängliche Datensätze ausgewählt, um das Projektziel der Reproduzierbarkeit und niedriger Einstiegshürden zu unterstützen. {% endif %}

{% if lang == "en" %} Input data: Sentinel-2 multispectral imagery was selected as the primary input data source. It is operated by the European Space Agency as part of the Copernicus program and provides near-global coverage with a site revisit frequency of five days. This ensures a high availability of observations. It is freely accessible via the Copernicus API. Its 13 spectral bands span the Visible, Near-Infrared (NIR), and Short-Wave Infrared (SWIR) regions of the electromagnetic spectrum (Copernicus Sentinel, n.d.)[13] Level-2A products were used, which provide atmospherically corrected Bottom-of-Atmosphere reflectance values. This improves the physical interpretability and comparability of the data. {% else %} Eingabedaten: Als primäre Eingabedatenquelle wurde multispektrale Sentinel-2-Bildgebung gewählt. Sie wird von der Europäischen Weltraumorganisation im Rahmen des Copernicus-Programms betrieben und bietet nahezu globale Abdeckung mit einer Wiederholungsfrequenz von fünf Tagen, wodurch eine hohe Verfügbarkeit an Beobachtungen gewährleistet ist. Der Zugriff erfolgt kostenfrei über die Copernicus-API. Die 13 Spektralbänder umfassen den sichtbaren Bereich, das Nahinfrarot (NIR) und das kurzwellige Infrarot (SWIR) (Copernicus Sentinel, n.d.)[13]. Verwendet wurden Level-2A-Produkte mit atmosphärisch korrigierten Bottom-of-Atmosphere-Reflexionswerten, die die physikalische Interpretierbarkeit und Vergleichbarkeit der Daten verbessern. {% endif %}

{% if lang == "en" %} From the full set of available bands, 10 were selected as model inputs: B2, B3, B4, B5, B6, B7, B8, B8A, B11, and B12. These bands cover critical spectral regions and enable inference of key biophysical properties relevant to SOC estimation, including vegetation condition, soil moisture, and crop growth status (Ngyuen et al., 2022)[15]. {% else %} Aus dem vollständigen Satz verfügbarer Bänder wurden zehn als Modelleingaben ausgewählt: B2, B3, B4, B5, B6, B7, B8, B8A, B11 und B12. Diese Bänder decken zentrale Spektralbereiche ab und ermöglichen die Ableitung relevanter biophysikalischer Eigenschaften für die SOC-Schätzung, einschliesslich Vegetationszustand, Bodenfeuchte und Wachstumszustand der Pflanzenarten (Ngyuen et al., 2022)[15]. {% endif %}

{% if lang == "en" %} Target variable: The LUCAS Topsoil dataset was selected as the source of ground-truth SOC measurements. It is coordinated by Eurostat and the European Commission’s Joint Research Centre and provides georeferenced soil samples collected across EU Member States from the topsoil layer (0–20 cm), which is most relevant for SOC dynamics in agricultural systems (European Commission, JRC, 2021)[16]. The dataset includes land-use classification, enabling filtering to cropland samples only. This ensures consistency between the target variable and the modelling domain. Its EU- wide, harmonized design makes it well-suited as ground truth for remote sensing– based SOC prediction. The upcoming LUCAS 2022 Topsoil release will enable future model retraining with more recent observations. {% else %} Zielvariable: Als Quelle für Referenzmessungen des organischen Bodenkohlenstoffs wurde der LUCAS-Topsoil-Datensatz gewählt. Er wird von Eurostat und dem Joint Research Centre der Europäischen Kommission koordiniert und umfasst georeferenzierte Bodenproben aus der Oberbodenschicht (0–20 cm) in allen EU-Mitgliedstaaten — der für die SOC-Dynamik in landwirtschaftlichen Systemen relevantesten Schicht (European Commission, JRC, 2021)[16]. Der Datensatz enthält eine Landnutzungsklassifikation, die eine Filterung auf Ackerproben ermöglicht und damit die Konsistenz zwischen Zielvariable und Modellierungsdomäne sicherstellt. Sein EU-weit harmonisiertes Design eignet sich als Ground Truth für fernerkundungsbasierte SOC-Vorhersagen. Die kommende Veröffentlichung von LUCAS 2022 Topsoil wird künftiges Modell-Retraining mit aktuelleren Beobachtungen ermöglichen. {% endif %}

{% if lang == "en" %} 3. Data collection and processing
The data collection and processing pipeline is based on a GitHub repository of the Computer Vision for Intelligent Mobility System Laboratory of the Technische Hochschule Ingolstadt (CVIMS, 2025)[17]. We updated the pipeline to the current Copernicus OData communication protocol, added a feature transformation, and modified it to be compatible with our interactive use case. Building on the existing CVIMS framework (2025)[17], the following outlines our team’s main contributions. {% else %} 3. Datenerhebung und -verarbeitung
Die Pipeline zur Datenerhebung und -verarbeitung basiert auf einem GitHub-Repository des Computer Vision for Intelligent Mobility System Laboratory der Technischen Hochschule Ingolstadt (CVIMS, 2025)[17]. Wir aktualisierten die Pipeline auf das aktuelle Copernicus-OData-Kommunikationsprotokoll, ergänzten eine Feature-Transformation und passten sie an unseren interaktiven Anwendungsfall an. Aufbauend auf dem bestehenden CVIMS-Framework (2025)[17] werden im Folgenden die wesentlichen Beiträge unseres Teams dargestellt. {% endif %}

{% if lang == "en" %} Feature transformation: Building on the selected raw band values, 13 additional predictor features were derived: 7 vegetation indices, 4 soil indices, and 2 cyclical temporal features encoding the month of observation. This feature engineering step follows Nguyen et al. (2022)[15], who demonstrated that derived indices correlate more strongly with agricultural SOC than raw spectral bands alone, with the Soil-Adjusted Vegetation Index (SAVI) identified as the single most important predictor. The inclusion of crop-growth indices is particularly appropriate for agricultural soils, which exhibit comparatively low topological variability, making spectral signals related to vegetation and soil surface conditions the dominant source of predictive information (Guo et al., 2021)[5]. {% else %} Feature-Transformation: Auf Basis der ausgewählten Rohbandwerte wurden 13 zusätzliche Prädiktorvariablen abgeleitet: sieben Vegetationsindizes, vier Bodenindizes sowie zwei zyklische zeitliche Merkmale zur Kodierung des Beobachtungsmonats. Dieser Schritt des Feature Engineerings folgt Nguyen et al. (2022)[15], die zeigten, dass abgeleitete Indizes stärker mit landwirtschaftlichem SOC korrelieren als Rohspektralbänder allein, wobei der Soil-Adjusted Vegetation Index (SAVI) als wichtigster Prädiktor identifiziert wurde. Die Einbeziehung von Wachstumsindizes ist insbesondere für landwirtschaftliche Böden geeignet, die eine vergleichsweise geringe topographische Variabilität aufweisen, sodass spektrale Signale von Vegetation und Bodenoberfläche die dominante Informationsquelle für Vorhersagen bilden (Guo et al., 2021)[5]. {% endif %}

{% if lang == "en" %} The two temporal features encode the survey month as sine and cosine components allowing the model to capture seasonal variation in surface reflectance while avoiding artificial discontinuities between December and January. {% else %} Die beiden zeitlichen Merkmale kodieren den Probenahmemonat als Sinus- und Kosinuskomponenten und ermöglichen es dem Modell, saisonale Schwankungen der Oberflächenreflexion zu erfassen, ohne künstliche Diskontinuitäten zwischen Dezember und Januar einzuführen. {% endif %}

{% if lang == "en" %} Interactive use case: A fixed reference min-max normalization was implemented for both Sentinel-2 band values and all derived indices. Unlike dataset-dependent normalization, which scales values relative to the minimum and maximum of whichever dataset is being processed, the fixed approach computes reference minimum and maximum values once from a representative dataset — here, the full German training set — and applies those constants consistently at every subsequent stage of the pipeline. {% else %} Interaktiver Anwendungsfall: Für Sentinel-2-Bandwerte und alle abgeleiteten Indizes wurde eine feste Referenz-Min-Max-Normalisierung implementiert. Im Gegensatz zur datensatzabhängigen Normalisierung, die Werte relativ zum Minimum und Maximum des jeweils verarbeiteten Datensatzes skaliert, berechnet der feste Ansatz Referenz-Minimum und -Maximum einmalig aus einem repräsentativen Datensatz — hier dem vollständigen deutschen Trainingsset — und wendet diese Konstanten in allen nachfolgenden Pipeline-Schritten konsistent an. {% endif %}

{% if lang == "en" %} This design decision was motivated to fit the interactive use case of AgroScan. At inference time, a farmer submits the GPS coordinates of their field, triggering the download of a small, location-specific Sentinel-2 datafile. A dataset-dependent normalization applied to this single observation would produce meaningless scaled values. The fixed reference approach ensures that the normalization applied to the farmer’s input is identical to that used during training, preserving the statistical relationship between features that the model learned. This makes the pipeline fully reusable from training to individual farmer queries without modification. Values outside the reference range are clipped to the unit interval to handle edge cases. {% else %} Diese Designentscheidung orientiert sich am interaktiven Anwendungsfall von AgroScan. Zur Inferenzzeit übergibt eine Landwirtin oder ein Landwirt die GPS-Koordinaten seines Feldes, woraufhin eine kleine, standortspezifische Sentinel-2-Datei heruntergeladen wird. Eine datensatzabhängige Normalisierung dieser einzelnen Beobachtung würde bedeutungslose skalierte Werte erzeugen. Der feste Referenzansatz stellt sicher, dass die Normalisierung der Eingabe identisch zu der im Training verwendeten ist und die statistischen Beziehungen zwischen den Merkmalen erhalten bleiben, die das Modell gelernt hat. Damit ist die Pipeline vom Training bis zu einzelnen Nutzerabfragen ohne Anpassung wiederverwendbar. Werte ausserhalb des Referenzbereichs werden auf das Einheitsintervall geclippt, um Randfälle abzufangen. {% endif %}

{{ "Normalization logic" if lang == "en" else "Normalisierungslogik" }}

{% if lang == "en" %} The fixed reference minimum and maximum values are computed once from a representative dataset using the python scripts calculate_band_ranges.py and calculate_index_ranges.py and saved to a respective .json file. For the normalization each raw value \(x\) is transformed to {% else %} Die festen Referenz-Minimum- und -Maximumwerte werden einmalig aus einem repräsentativen Datensatz mit den Python-Skripten calculate_band_ranges.py und calculate_index_ranges.py berechnet und in jeweils einer .json-Datei gespeichert. Für die Normalisierung wird jeder Rohwert \(x\) wie folgt transformiert: {% endif %}

\[x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}}\]

{% if lang == "en" %} and then, if needed, clipped to the unit interval: \(x' \leftarrow \min(1,\max(0,x'))\). If \(x_{\max}=x_{\min}\) the implementation returns 0 to avoid division by zero and NaN/inf values are replaced with 0 afterwards. {% else %} und anschliessend, falls nötig, auf das Einheitsintervall geclippt: \(x' \leftarrow \min(1,\max(0,x'))\). Falls \(x_{\max}=x_{\min}\), gibt die Implementierung 0 zurück, um eine Division durch null zu vermeiden; NaN-/Inf-Werte werden anschliessend durch 0 ersetzt. {% endif %}

{{ "ML model" if lang == "en" else "ML-Modell" }}

{% if lang == "en" %} 1. Selection of model
The model architecture and implementation used in this work are based on the approach presented by Kammerlander (2025)[14]. Kammerlander evaluated three machine learning approaches for predicting soil nutrient levels across Europe: XGBoost, Random Forest, and Fully Connected Neural Networks (FCNNs). Model performance was assessed using Root Mean Squared Error (RMSE) for several soil properties, including phosphorus, nitrogen, potassium, and pH. {% else %} 1. Modellauswahl
Architektur und Implementierung des in dieser Arbeit verwendeten Modells orientieren sich am Ansatz von Kammerlander (2025)[14]. Kammerlander evaluierte drei Verfahren des maschinellen Lernens zur Vorhersage von Bodennährstoffgehalten in Europa: XGBoost, Random Forest und Fully Connected Neural Networks (FCNNs). Die Modellleistung wurde anhand des Root Mean Squared Error (RMSE) für mehrere Bodeneigenschaften bewertet, darunter Phosphor, Stickstoff, Kalium und pH. {% endif %}

{% if lang == "en" %} The results showed that the FCNN architecture achieved the best overall performance. While XGBoost and Random Forest produced similar results for pH estimation, FCNN outperformed the other methods for nutrients with high variability. {% else %} Die Ergebnisse zeigten, dass die FCNN-Architektur die insgesamt beste Leistung erzielte. Während XGBoost und Random Forest für die pH-Schätzung vergleichbare Resultate lieferten, übertraf FCNN die anderen Verfahren bei Nährstoffen mit hoher Variabilität. {% endif %}

{% if lang == "en" %} Within the LUCAS dataset filtered for German croplands, organic carbon (OC) has a mean value of 18.18 g/kg and a standard deviation of ±8.91 g/kg, indicating substantial variability across samples. {{ "What is a FCNN" if lang == "en" else "Was ist ein FCNN" }}

{% if lang == "en" %} FCNNs, also referred to as multilayer perceptron, are feedforward artificial neural networks in which each neuron of one layer is connected to all neurons of the subsequent layer. FCNNs are trained using the backpropagation algorithm introduced by Rumelhart (1986)[19]. Through multiple hidden layers and nonlinear activation functions, FCNNs are capable of learning complex nonlinear relationships between input features and target variables. {% else %} FCNNs, auch als Multilayer-Perceptron bezeichnet, sind feedforward-künstliche neuronale Netze, in denen jedes Neuron einer Schicht mit allen Neuronen der folgenden Schicht verbunden ist. FCNNs werden mit dem Backpropagation-Algorithmus trainiert, den Rumelhart (1986)[19] einführte. Durch mehrere versteckte Schichten und nichtlineare Aktivierungsfunktionen sind FCNNs in der Lage, komplexe nichtlineare Zusammenhänge zwischen Eingabevariablen und Zielgrössen zu modellieren. {% endif %}

{{ "The ML model behind AgroScan" if lang == "en" else "Das ML-Modell hinter AgroScan" }}

{{ "Model architecture" if lang == "en" else "Modellarchitektur" }}
{% if lang == "en" %} The network is constructed dynamically as a sequence of linear layers with ReLU activation and dropout after each hidden layer, followed by a single linear output neuron for predicting OC. Model training is performed with backpropagation in PyTorch using mini-batches and RMSE as optimization objective. Weight decay of 0.01 is applied for regularization. {% else %} Das Netz wird dynamisch als Sequenz linearer Schichten mit ReLU-Aktivierung und Dropout nach jeder versteckten Schicht aufgebaut, gefolgt von einem linearen Ausgabeneuron zur OC-Vorhersage. Das Training erfolgt per Backpropagation in PyTorch mit Mini-Batches; als Optimierungsziel dient der RMSE. Zur Regularisierung wird ein Weight Decay von 0,01 angewendet. {% endif %}

{{ "Model training" if lang == "en" else "Modelltraining" }}
{% if lang == "en" %} For every trial, a new FCNN architecture is built from the sampled layer widths and dropout rates, trained for 20 epochs, and evaluated on the held-out test set. The currently best model (lowest test RMSE so far) is saved to disk as a checkpoint file (.pth), together with architecture metadata (input size, hidden sizes, dropout rates, output size, and loss type). For FCNN training, the dataset is split once into train and test subsets using an 80/20 ratio. Thus, FCNN validation is a single random holdout split. {% else %} In jedem Trial wird eine neue FCNN-Architektur aus den variierten Schichtbreiten und Dropout-Raten aufgebaut, 20 Epochen trainiert und auf dem Hold-out-Testset evaluiert. Das bislang beste Modell (niedrigster Test-RMSE) wird als Checkpoint-Datei (.pth) gespeichert, zusammen mit Architektur-Metadaten (Eingabegrösse, versteckte Grössen, Dropout-Raten, Ausgabegrösse und Loss-Typ). Für das FCNN-Training wird der Datensatz einmalig im Verhältnis 80/20 in Trainings- und Testsubset aufgeteilt. Die FCNN-Validierung erfolgt somit als einzelner zufälliger Hold-out-Split. {% endif %}

{{ "Model employment" if lang == "en" else "Modelleinsatz" }}
{% if lang == "en" %} The prediction is implemented in run_pipeline_from_gps.py. The same feature- processing logic used during training is reused to prepare the dataset. Sentinel-2 imagery for each location is downloaded, after which the pixel values around the sampled point are extracted, the spectral bands are normalized, and the derived features are computed. The transformed dataset is then passed to the neural network, which outputs the predicted carbon content value, stored as OC in the repository. {% else %} Die Vorhersage ist in run_pipeline_from_gps.py implementiert. Dieselbe Feature-Verarbeitungslogik wie im Training wird zur Datensatzvorbereitung wiederverwendet. Sentinel-2-Bilddaten für jeden Standort werden heruntergeladen; anschliessend werden Pixelwerte im Umfeld des Probenpunkts extrahiert, die Spektralbänder normalisiert und abgeleitete Merkmale berechnet. Der transformierte Datensatz wird an das neuronale Netz übergeben, das den vorhergesagten Kohlenstoffgehalt ausgibt und als OC im Repository speichert. {% endif %}

The wrapper enables the user to interact with the model: They select their field, from there the field coordinates are extracted in a grid system and used as input for the model wrapper. Modellinteraktion
Die Pipeline für Datenerhebung, -verarbeitung und Modellvorhersage wurde in ein Wrapper-Skript (run_pipeline_from_gps.py) zusammengefasst und in das Website-Backend integriert. {% if lang == "en" %} To speed up processing, the system reuses previously downloaded Sentinel scenes and cropped outputs whenever possible. Raw Sentinel scenes are cached as raw data, while cropped per-point outputs are stored together with metadata. The backend generates a fixed 60×60 m grid over the selected field polygon and uses the grid centers as analysis points. To maximize cache reuse, the grid is dynamically aligned to existing cached points by selecting the anchor position with the highest overlap. If a cached point is found within a 10 m radius, the existing cropped image is reused instead of generating a new one. As a result, only when no data is available, missing scenes are downloaded and cropped significantly reducing processing time. {% else %} Zur Beschleunigung der Verarbeitung werden bereits heruntergeladene Sentinel-Szenen und zugeschnittene Ausgaben nach Möglichkeit wiederverwendet. Rohe Sentinel-Szenen werden als Rohdaten zwischengespeichert, zugeschnittene Punkt-Ausgaben gemeinsam mit Metadaten gespeichert. Das Backend erzeugt ein festes 60×60-m-Raster über das ausgewählte Feldpolygon und nutzt die Rasterzentren als Analysepunkte. Zur Maximierung der Cache-Nutzung wird das Raster dynamisch an vorhandene zwischengespeicherte Punkte ausgerichtet, indem die Ankerposition mit der grössten Überlappung gewählt wird. Liegt ein zwischengespeicherter Punkt innerhalb eines 10-m-Radius, wird das vorhandene zugeschnittene Bild wiederverwendet, statt ein neues zu erzeugen. Fehlende Szenen werden nur bei Bedarf heruntergeladen und zugeschnitten, was die Verarbeitungszeit signifikant reduziert. {% endif %}

{% if lang == "en" %} This same mechanism can be extended to a background sync process that proactively downloads and updates cached scenes for a farm/region when new Sentinel acquisitions arrive, enabling near-instant analysis for farmers without waiting for on- demand downloads. {% else %} Derselbe Mechanismus lässt sich auf einen Hintergrund-Synchronisationsprozess erweitern, der bei neuen Sentinel-Aufnahmen proaktiv zwischengespeicherte Szenen für einen Betrieb oder eine Region aktualisiert und nahezu sofortige Analysen ermöglicht, ohne auf On-demand-Downloads warten zu müssen. {% endif %}

{{ "Ethical Considerations" if lang == "en" else "Ethische Überlegungen" }}

{% if lang == "en" %} Remote sensing is widely used for environmental monitoring, agriculture, and climate research, but it also raises ethical concerns that are often overlooked (Benett et al., 2024)[10]. In AgroScan, two main concerns were identified. {% else %} Fernerkundung wird breit für Umweltmonitoring, Landwirtschaft und Klimaforschung eingesetzt, wirft jedoch ethische Fragestellungen auf, die häufig übersehen werden (Benett et al., 2024)[10]. Im Kontext von AgroScan wurden zwei zentrale Bedenken identifiziert. {% endif %}

{% if lang == "en" %} First, remote sensing creates a physical distance between data collection and affected communities. This may impose normative assumptions about soil organic carbon (SOC) management without fully considering local knowledge, consent, and farming practices. While AgroScan can empower farmers to use sustainable soil management, it could also lead to unintended impact like institutions using it to impose and monitor regulations unsuited for the local context. {% else %} Erstens schafft Fernerkundung eine räumliche Distanz zwischen Datenerhebung und betroffenen Gemeinschaften. Dadurch können normative Annahmen zur Bewirtschaftung des organischen Bodenkohlenstoffs (SOC) entstehen, ohne lokales Wissen, Einwilligung und landwirtschaftliche Praxis vollständig zu berücksichtigen. AgroScan kann Landwirtinnen und Landwirte bei nachhaltiger Bodenbewirtschaftung stärken, birgt jedoch auch unbeabsichtigte Effekte — etwa wenn Institutionen es nutzen, um unpassende Vorgaben durchzusetzen und zu überwachen. {% endif %}

{% if lang == "en" %} To address this, AgroScan will be released as an open-source project on GitHub with a detailed README and only publicly available, free datasets to reduce technical and financial barriers. The farmer can understand, reproduce and adapt the methodology and use it to advocate for regulations in front of policymakers. Future releases aim to include a community forums and input of local knowledge (e.g., soil type, uploaded pictures) into model to support farmer participation and platform improvement and offer a low-tech method to impact the development of the AgroScan. {% else %} Als Gegenmassnahme wird AgroScan als Open-Source-Projekt auf GitHub mit ausführlichem README und ausschliesslich öffentlich verfügbaren, kostenfreien Datensätzen veröffentlicht, um technische und finanzielle Barrieren zu senken. Landwirtinnen und Landwirte können die Methodik verstehen, reproduzieren und anpassen sowie sie bei der Interessenvertretung gegenüber politischen Entscheidungsträgerinnen und -trägern einsetzen. Künftige Versionen sollen Community-Foren und die Einbindung lokalem Wissens (z. B. Bodentyp, hochgeladene Bilder) in das Modell umfassen, um die Beteiligung von Landwirtinnen und Landwirten sowie die Weiterentwicklung der Plattform zu fördern und niederschwellige Einflussnahme auf die Entwicklung von AgroScan zu ermöglichen. {% endif %}

{% if lang == "en" %} Second, AgroScan has limited transferability beyond its European focus, shaped by available datasets and the team’s familiarity with German agricultural conditions. Applying the tool to a different regional and social context may create unpredicted ethical risks e.g., related to indigenous sovereignty, authoritarian misuse of agricultural information, or mismatches with local farming needs. {% else %} Zweitens ist die Übertragbarkeit von AgroScan über den europäischen Fokus hinaus begrenzt, geprägt durch verfügbare Datensätze und die Vertrautheit des Teams mit deutschen landwirtschaftlichen Bedingungen. Die Anwendung des Werkzeugs in anderen regionalen und sozialen Kontexten kann unvorhergesehene ethische Risiken erzeugen — etwa im Hinblick auf indigene Souveränität, autoritären Missbrauch landwirtschaftlicher Informationen oder Fehlpassungen zu lokalen Anbaubedürfnissen. {% endif %}

{% if lang == "en" %} Therefore, transferring AgroScan to other regions requires a strong understanding of local social and agricultural contexts, ideally through participatory engagement with local communities. In many lower-income regions, limited soil sampling data also creates technical barriers, making participatory soil sampling campaigns important for developing socially responsible remote sensing tools. {% else %} Eine Übertragung auf andere Regionen erfordert daher ein fundiertes Verständnis lokaler sozialer und agronomischer Kontexte, idealerweise durch partizipative Einbindung lokaler Gemeinschaften. In vielen einkommensschwächeren Regionen erschweren zudem begrenzte Bodenproben-Daten die technische Umsetzung, weshalb partizipative Bodenprobenkampagnen wichtig sind, um sozial verantwortungsvolle Fernerkundungswerkzeuge zu entwickeln. {% endif %}

{{ "Evaluation" if lang == "en" else "Evaluation" }}

{% if lang == "en" %} AgroScan investigated the question: how can interactive machine learning be utilized to empower farmers to monitor and manage carbon stock in their agricultural soils? The project successfully addresses this through three channels. First, a simple step-by- step analysis workflow with an efficient repeated-sampling feature directly fulfills the user requirement of quick, routine SOC assessment. Second, a card-based, hierarchical personal dashboard tailored to carbon farming confers technical agency to the farmer, enabling long-term comparison of SOC trends across fields to evaluate the impact of SSM practices. Third, an open-source architecture with publicly documented methodology closes the transparency and accessibility gaps identified in the literature review. This differentiates AgroScan from existing commercial tools. Taken together, these contributions constitute a working proof of concept for a farmer-facing, interactive SOC monitoring platform. {% else %} AgroScan untersuchte die Frage: Wie kann interaktives maschinelles Lernen genutzt werden, um Landwirtinnen und Landwirte zu befähigen, den Kohlenstoffvorrat in ihren landwirtschaftlichen Böden zu überwachen und zu steuern? Das Projekt adressiert diese Frage über drei Wege. Erstens erfüllt ein einfacher schrittweiser Analyse-Workflow mit effizienter Funktion für wiederholte Analysen die Nutzeranforderung einer schnellen, routinemässigen SOC-Bewertung. Zweitens verleiht ein kartenbasiertes, hierarchisches persönliches Dashboard, zugeschnitten auf Carbon Farming, Landwirtinnen und Landwirten technische Handlungsfähigkeit und ermöglicht langfristige SOC-Trendvergleiche zur Bewertung der Wirkung von SSM-Massnahmen. Drittens schliesst eine Open-Source-Architektur mit öffentlich dokumentierter Methodik die Transparenz- und Zugänglichkeitsdefizite aus der Literaturübersicht. Damit unterscheidet sich AgroScan von bestehenden kommerziellen Werkzeugen. Insgesamt bilden diese Beiträge einen funktionierenden Proof of Concept für eine landwirtschaftspraxisorientierte, interaktive SOC-Monitoring-Plattform. {% endif %}

{% if lang == "en" %} Given the limited project timeframe, several limitations remain. On the model side, the small training dataset (n=270, LUCAS 2015) constrains predictive accuracy. This can be improved by incorporating data from neighboring EU countries and retraining on the upcoming LUCAS 2022 release expected in Q3 2026. The current feature set further omits predictors with established value, most notably Sentinel-1 SAR-derived features, which Nguyen et al. (2022)[15] demonstrated correlate more strongly with agricultural SOC than optical data alone, as well as crop yield, weather, and elevation data. Integrating farmer-provided local inputs such as soil type and bulk density could additionally bridge the physical separation inherent to remote sensing and improve model accuracy. Spatially, the current 60×60m pixel resolution limits within-field variability insights for smaller parcels. This could be reduced to 10×10m by leveraging the full Sentinel-2 resolution and applying interpolation for bands with higher resolution. On the visualization side, the current SOC threshold classification is derived from the aggregate LUCAS distribution and does not account for local soil conditions, land use, or climate. Incorporating location and farmer-provided soil type data would enable more regionally specific and agronomically meaningful threshold definitions. A detailed overview of planned platform developments addressing these limitations is provided on the AgroScan Future Features page. {% else %} Aufgrund des begrenzten Projektzeitraums verbleiben mehrere Einschränkungen.
