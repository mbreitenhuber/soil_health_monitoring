How it works

From polygon to zone map in seconds

Select the polygon drawing tool on the map, click around the edges of your field, and start the analysis.

The program splits the bounding box into a 60m x 60m grid and computes a quality score for each cell using a machine learning model.

Try out now →
Machine Learning Model

Plug in your own model

Satellite driven decision support

The machine learning model is trained on ESA's Sentinel-2 data. The Program splits the field in 60m x 60m cells and the model uses various vegetation indices to predict the quality for each cell. The result is a zone map with a quality score for each cell.
